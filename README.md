# Simple AI Agent

A simple command-line AI chatbot built with Python and the Google Gemini API. The application accepts user input, sends it to the Gemini model, and returns intelligent, context-aware responses in a conversational format.

## Features

- Natural language conversations
- Powered by Google Gemini API
- Simple command-line interface
- Continuous chat until the user exits
- Easy to understand and extend

## Technologies Used

- Python
- Google Gemini API
- Prompt-based AI interaction

## Installation

1. Clone the repository.
2. Install the Google GenAI package:
   ```bash
   pip install google-genai
   ```
3. Add your Gemini API key:
   ```python
   API_KEY = "YOUR_API_KEY"
   ```
4. Run the application:
   ```bash
   python main.py
   ```

## Example

```
You: What is Artificial Intelligence?
AI: Artificial Intelligence (AI) is the simulation of human intelligence by machines...
```
